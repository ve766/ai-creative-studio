# infra

本目录用于本地开发编排与（未来的）部署配置。

## 重要

**正式运行不依赖 Docker，也不需要自建服务器。** 生产环境使用托管服务，详见
`docs/cloud-architecture.md`。

## 本地可选服务

```bash
docker compose -f infra/docker/docker-compose.yml up -d
```

仅提供本地 PostgreSQL，用于阶段 2 的离线开发与迁移脚本验证。凭据为本地开发用途，
**不得用于任何非本地环境**。

## 部署

部署配置与流程将在阶段 8 补齐，包含：

- 托管平台部署配置
- 环境变量清单（对照 `.env.example`）
- 数据库迁移脚本执行顺序
- 开发 / 预览 / 生产环境区分
- 部署与回滚流程
- 日志与监控说明
- 备份与恢复说明
- 供应商故障处理方案
