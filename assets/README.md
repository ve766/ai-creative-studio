# assets

产品素材、3D 模型与字体的存放位置。**当前全部为空**（v0.1.0 未引入任何二进制素材）。

```
assets/
  templates/   产品预览图与叠加层（遮挡/纹理/光照）
  models/      glTF/GLB 3D 模型
  fonts/       内嵌字体文件
  fixtures/    测试用固定素材
```

## 规则

1. 只放入**授权明确**的素材，并在同目录记录来源与授权
2. 大文件谨慎提交；优先使用托管对象存储，仓库只保留必要的小体积示例
3. 模板叠加层资源加入后必须递增对应模板的 `version`
4. 3D 模型必须记录来源、授权、体积与 UV 映射说明（见 `docs/template-format.md`）
5. 测试夹具必须是可公开分发的素材，不得使用真实用户数据

当前 UI 使用的模板预览图为 `apps/web/public/templates/*.svg`（手绘矢量占位图，无版权风险）。
