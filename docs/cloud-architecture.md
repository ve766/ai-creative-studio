# 云端服务架构、供应商对比、费用模型与迁移风险

> 本文件是阶段 1 交付的一部分（补充要求第 10 条），在接入任何云端服务**之前**完成。
> 所有报价与免费额度均为**待核实**状态：正式接入前必须逐一确认当前地区可用性、价格、额度与服务条款。
> 本文件不构成采购决策，任何付费资源开通都需要明确授权。

## 1. 原则

1. Cloud-first、API-first、Managed Services 优先
2. 不购买或维护物理服务器、云主机、GPU 服务器、数据库主机
3. 不自行运维 Linux、Nginx、GPU 驱动、Kubernetes
4. Docker 仅用于本地开发与测试，不得成为正式运行的必要条件
5. 所有外部服务通过 Adapter 接口接入，业务代码不绑定供应商

## 2. 目标架构

```
浏览器 (Next.js 前端)
  │  1. 认证 -> 托管认证服务
  │  2. 上传 -> 预签名 URL -> 对象存储直传
  │  3. 业务 -> HTTPS API (Next.js Route Handlers, /api/v1)
  │  4. 长任务 -> 任务服务 -> 前端轮询任务状态
  ▼
服务端（托管函数）
  ├─ 认证校验 / 权限校验 / Schema 校验
  ├─ Postgres（托管，启用 RLS）元数据与额度
  ├─ 对象存储（私有桶 + 短期授权 URL）
  ├─ AI Provider 适配层（托管 HTTPS API）
  └─ 支付服務 + webhook 校验
```

## 3. Provider 接口（必须实现的最小集合）

| 接口 | 责任 | 关键要求 |
| --- | --- | --- |
| `AuthenticationProvider` | 注册、登录、会话、用户身份 | 服务端校验身份，不信任前端声明 |
| `ObjectStorageProvider` | 预签名上传、私有下载、删除、生命周期 | 短期有效、限定路径与权限 |
| `ImageGenerationProvider` | 文本生成图案、透明背景图案 | 超时、重试、限流、用量记录 |
| `ImageEditingProvider` | 图案扩展、局部修改 | 输入输出类型固定 |
| `BackgroundRemovalProvider` | 背景移除、透明边缘检查 | 明确失败与降级 |
| `SceneMockupProvider` | 实拍照片场景融合 | 保存全部变换参数 |
| `PaymentProvider` | 方案、结账、订阅、webhook | 幂等、服务端校验、可追踪流水 |
| `JobQueueProvider` | 长任务排队与状态 | queued/processing/succeeded/failed/cancelled |

每个 Provider 必须提供：明确输入输出类型、统一错误格式、超时、有限重试、速率限制、用量/费用记录、配置检查、可替换实现、自动化测试（使用假实现）。

## 4. 供应商候选对比

> 状态列含义：**待核实** = 尚未验证当前地区可用性与条款；不要当作已确认结论。

### 4.1 Web 部署

| 候选 | 适用性 | 优点 | 风险 / 待核实 |
| --- | --- | --- | --- |
| Vercel | Next.js 原生 | 零运维、预览环境、与 Next.js 深度集成 | 函数执行时长与体积限制、流量计费、地区可用性 |
| Cloudflare Pages + Workers | 边缘运行 | 冷启动低、与 R2 同厂商 | Node 兼容性、构建时长限制 |
| Netlify | 通用静态 + 函数 | 生态成熟 | 函数时长限制、Next.js 适配成熟度 |

### 4.2 数据库与认证

| 候选 | 适用性 | 优点 | 风险 / 待核实 |
| --- | --- | --- | --- |
| Supabase（Auth + Postgres） | 认证 + 数据库一体 | RLS、托管迁移、免费额度 | 连接数限制、免费项目暂停策略、地区 |
| Neon / 其他托管 Postgres + 独立认证 | 分离关注点 | 灵活 | 需自行编排认证，集成成本更高 |

### 4.3 对象存储

| 候选 | 适用性 | 优点 | 风险 / 待核实 |
| --- | --- | --- | --- |
| Cloudflare R2 | 图片/模型存储 | 无 egress 费用、S3 兼容 | 免费额度、地区延迟 |
| Supabase Storage | 与认证同厂商 | RLS 集成、签名 URL | 容量与带宽额度 |

### 4.4 AI 图像能力

要求：通过 HTTPS API 调用，明确商业使用条款与数据留存政策。

| 能力 | 候选类型 | 待核实事项 |
| --- | --- | --- |
| 文本生成图案 | 托管文生图 API | 分辨率、商用授权、内容审核策略、单次价格 |
| 背景移除 | 托管抠图 API | 边缘质量、透明通道保真、批量限制 |
| 场景融合 | 托管图像编辑/合成 API | 是否支持透视与光照控制、是否保留原图构图 |

**不自行训练基础大模型，不默认购买 GPU。**

### 4.5 3D

- 浏览器内 Three.js 完成实时预览与材质映射（无服务端成本）
- 仅在确实需要高质量离线渲染时评估付费云端渲染服务

### 4.6 任务队列

| 候选类型 | 适用性 | 待核实 |
| --- | --- | --- |
| 托管工作流/队列服务 | 长任务、重试、状态机 | 单任务时长、并发额度、价格 |
| 函数 + 任务表 + 轮询 | 最低成本起步 | 需要自己实现重试与幂等 |

### 4.7 支付

- 先确认目标市场、商户资格、币种与订阅/退款/webhook 能力，再选择供应商
- 支付状态只能由经过验证的服务端通知或可信服务端查询更新

### 4.8 监控

- 托管错误监控 + 平台日志；不自行搭建监控服务器

## 5. 费用模型（估算框架，非报价）

| 项目 | 计费维度 | 免费额度可用性 | 保护措施 |
| --- | --- | --- | --- |
| Web 托管 | 请求数、带宽、构建时长 | 通常有 | 设置每日用量告警 |
| Postgres | 存储、计算、连接数 | 通常有 | 限制连接池、定期清理 |
| 对象存储 | 存储量、请求数、egress | 视供应商 | 图片尺寸上限、生命周期清理 |
| AI 图像 | 每次调用 | 视供应商 | 单用户额度、每日上限、费用预算检查 |
| 支付 | 交易手续费 | 无 | 处于未开通状态 |
| 监控 | 事件数 | 通常有 | 采样 |

**阶段 1 实际运行成本：0**（无任何外部付费服务）。

成本控制要求：

- 每种外部服务的配置说明与预计计费项目
- AI 单次调用费用记录（供应商提供数据时）
- 每日/每月用量上限、单用户额度、异常增长保护
- 服务不可用时的降级策略
- 不假设免费计划适合长期商业运营，也不假设所有 API 支持硬性费用上限

## 6. 托管平台限制（设计时必须检查）

- 单次请求执行时间限制
- 请求/响应体大小限制
- 函数内存与运行时长
- 数据库连接数
- 对象存储请求与带宽限制
- AI API 的输入输出限制
- 任务重试与幂等要求
- 免费与付费计划差异

结论：耗时的 AI 处理、批量渲染、导出必须通过任务 ID + 异步状态管理，前端轮询或使用托管实时服务；不依赖永久运行的自建服务器。

## 7. 文件上传策略

1. 前端向服务端申请预签名 URL（服务端校验权限、限定对象路径与有效期）
2. 前端直传对象存储（不经服务端转发大文件）
3. 上传完成后调用 `POST /api/v1/assets/complete` 验证对象并登记元数据
4. 默认私有桶，下载通过短期授权 URL 或权限校验接口

## 8. 数据与供应商迁移

- 标准 PostgreSQL 结构，不绑定供应商专有特性
- 项目 JSON 与供应商无关；仅保存必要的外部引用（assetId、modelId、jobId）
- 通过环境变量区分 dev / preview / production
- 数据库与对象存储必须有备份、导出、恢复策略
- 唯一数据副本不得只存在于临时服务的本地磁盘
- 提供供应商替换与数据迁移说明

## 9. 迁移风险评估

| 风险 | 影响 | 缓解措施 | 状态 |
| --- | --- | --- | --- |
| 本地存储 → 云端数据库 | 用户已有本地项目需迁移 | 保留 JSON 导出/导入；提供一键上传迁移入口 | 待实施 |
| 图片内联 dataURL → 对象存储 | 项目结构中的 `src` 语义变化 | 已预留 `assetId` 字段；解析时二者兼容 | 已预留 |
| Schema 演进 | 旧项目打不开 | `schemaVersion` + 迁移函数 + 迁移测试 | 已实现 |
| 免费额度耗尽导致服务中断 | 用户无法保存 | 用量监控与告警；降级到只读本地模式 | 待实施 |
| AI 供应商数据留存政策 | 用户设计外泄 | 接入前审核条款；提供不上传第三方服务的选项 | 待实施 |
| 供应商锁定 | 迁移成本高 | Adapter 接口 + 只存标准引用 | 已实现骨架 |
| 函数超时 | 长任务失败 | 任务队列 + 幂等重试 | 待实施 |

## 10. 接入顺序（与开发阶段对应）

1. 阶段 2：认证 + Postgres + 对象存储 + 项目 CRUD
2. 阶段 3：AI 图案 Provider + 额度
3. 阶段 4：场景贴图 Provider
4. 阶段 5：3D（浏览器内，无服务端成本）
5. 阶段 6：印刷输出（服务端渲染或 Worker）
6. 阶段 7：支付与订阅
7. 阶段 8：安全审查、备份恢复演练、部署文档

**正式部署、付费服务开通、域名切换、生产数据库迁移必须获得明确授权。**
