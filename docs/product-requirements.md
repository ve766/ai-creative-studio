# 产品需求

## 1. 产品定位

AI 文创设计工坊（AI Creative Studio）让用户把自己的图案、文字、照片或 AI 生成图案，准确地放置到真实文创产品上，完成设计、预览、保存、导出，并在后续阶段支持印刷生产。

目标用户：普通消费者、文创爱好者、独立设计师、印刷商、文创商家、小型品牌。
目标平台：PC（Windows / macOS 浏览器）、移动端（iOS Safari、Android 浏览器）。

**不是**：单纯的 AI 绘图网站、表情包制作器、只有静态页面的 UI Demo。

## 2. 三种核心设计模式

| 模式 | 说明 | 阶段 | 状态 |
| --- | --- | --- | --- |
| A. 智能模板贴图 | 在标准产品模板上拖动、缩放、旋转、裁切图案 | 1 | 已实现 |
| B. 真实场景 AI 贴图 | 上传产品实拍照片，识别可贴图区域，按透视/遮挡/纹理/光照融合 | 4 | 未实现 |
| C. 3D 立体产品设计 | 在可旋转的 3D 模型上编辑贴图，多角度预览与效果图输出 | 5 | 未实现 |

## 3. 页面与流程

### 3.1 首页

- 产品介绍与开始设计入口
- 核心能力卡片（明确标注「已实现 / 未配置」）
- 模板库预览、最近项目
- 所有关键按钮必须执行真实动作

验收：点击「选择产品模板开始设计」进入模板库；点击模板卡片「开始设计」创建项目并跳转编辑器；「我的项目」列出本地项目。

### 3.2 模板库

- 10 个示例模板：马克杯、帆布袋、T 恤、手机壳、笔记本、海报、鼠标垫、抱枕、水杯、贴纸
- 每个模板包含：稳定 ID、版本、类别、名称、预览图、画布尺寸与坐标系、可编辑区域、安全区、出血区、可选叠加层、可选 3D 配置、输出规格
- 按类别筛选

验收：筛选切换正确；模板卡片显示版本与「示例模板」标记；同一模板 ID 的 `version` 稳定。

### 3.3 我的项目

- 列表按更新时间倒序
- 打开编辑、复制、导出 JSON、导入 JSON、删除
- 显示本地存储占用

验收：删除需二次确认；导入非法 JSON 给出明确错误且不写入数据；复制生成新 ID。

### 3.4 2D 编辑器

必须实现且已实现：

上传 PNG/JPEG/WebP、添加文字图层、选择/移动/缩放/旋转/删除、图层顺序、复制、锁定与隐藏、透明度、适应画布、撤销重做、自动保存与手动保存、项目重命名、画布缩放平移适应、PNG 导出、移动端触控、错误/加载/空状态。

未实现（已知限制）：裁切交互 UI（数据结构已就绪）、混合模式、多选。

### 3.5 导出与预检

- 「导出效果图 PNG」：画布原始分辨率
- 「导出印刷参考 PNG」：按目标 DPI 计算像素，最大 4 倍，**不通过放大低分辨率图片伪造细节**
- 预检规则：空设计（warning）、低分辨率（error/warning）、超出安全区（info）

## 4. 后续阶段验收标准

### 阶段 2 云端项目

- 用户可注册登录，只能访问自己的项目（越权请求返回 403/404）
- 项目 CRUD 通过 API 完成，前端不再依赖 localStorage 作为唯一存储
- 图片通过预签名 URL 客户端直传对象存储
- 自动保存失败有明确反馈

### 阶段 3 AI 图案

- 未配置 Provider 时接口返回 `NOT_CONFIGURED`，UI 显示配置提示，不展示伪造结果
- 支持文生图、背景移除；任务状态含 queued/processing/succeeded/failed
- 失败任务按规则返还额度，重复请求不重复扣减（幂等）

### 阶段 4 场景贴图

- 保存原图、原设计图、变换参数，可重新调整而非仅保存一张合成图
- 结果明确标注「仅用于效果展示，非印刷生产文件」

### 阶段 5 3D

- 模型加载失败有明确提示
- 贴图映射可重复验证（相同输入产生相同输出）
- 至少 1–2 种产品具备可验证的 UV 映射

### 阶段 6 印刷生产

- 导出尺寸与指定规格一致
- 低分辨率与越界设计触发预检警告
- 效果图与生产文件在 UI 与文件名上明确区分

### 阶段 7 订阅支付

- 前端无法提升权限
- webhook 重复投递不重复记账
- 失败支付不激活订阅
- 额度变化有可追踪流水

## 5. 非功能需求

- 中文优先；统一色彩、字体、间距、按钮与表单体系
- 所有关键功能具备加载、成功、失败、空状态
- 保存状态明确
- 不使用大量无实际作用的按钮
- 不以动画、渐变、装饰代替核心功能
- 关键流程可通过键盘或触控完成
